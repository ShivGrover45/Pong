# Pong

A Pong clone built with Pygame CE.

## Features
- Classic 2-player-feel Pong (player vs AI)
- Adjustable AI difficulty (proportional steering)
- Score tracking, main menu, game-over screen

## Running locally
pip install pygame-ce
python main.py

## Controls
- ↑ / ↓ — move paddle
- SPACE — start / play again
- ESC — quit / back to menu
